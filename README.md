# Shohstore

Минималистичный интернет-магазин компьютеров и комплектующих. React + TypeScript + Vite, Express и SQLite. Интерфейс на русском, узбекском и английском, светлая и тёмная темы, адаптивная вёрстка. Шрифт и векторные иллюстрации доступны локально. Основной текст увеличен; переходы страниц используют короткое затухание без тяжёлых эффектов и отключаются при `prefers-reduced-motion`.

## Как открыть скачанный ZIP

Полностью распакуйте архив в обычную папку. **Откройте `index.html` двойным щелчком**: это готовая автономная версия, а не исходный файл Vite. Скрипты, стили, шрифты, векторные иллюстрации и каталог уже встроены в HTML. Для просмотра не нужны Node.js, установка пакетов или Интернет. Можно открывать каталог, искать товары, смотреть характеристики, переключать язык и тему, добавлять комплектующие в конструктор и считать стоимость.

Регистрация, настоящая база пользователей, заказы и админ-панель требуют работающего сервера. Автономная версия объясняет, как его запустить, и не имитирует регистрацию или сохранение заказов.

## Полный магазин с базой — простой запуск

1. Установите **Node.js 24 или новее** с [официального сайта](https://nodejs.org/).
2. Полностью распакуйте ZIP. Не запускайте файлы внутри окна архива.
3. Откройте файл для своей системы:
   - Windows: **`START-SHOHSTORE.bat`**.
   - macOS: **`START-SHOHSTORE.command`**.
   - Linux: **`START-SHOHSTORE.sh`** (или `sh START-SHOHSTORE.sh` в терминале).

Первый запуск устанавливает зависимости и собирает сайт, поэтому нужен Интернет. Затем запускается сервер, проверяется готовность и открывается браузер. Оставьте окно запуска открытым, пока используете магазин; Ctrl+C останавливает сервер. При ошибке окно Windows/macOS остаётся открытым с объяснением.

Через терминал тот же запуск выполняется командой из распакованной папки:

```sh
npm run launch
```

Права администратора компьютера не нужны для самого магазина. Для создания администратора **магазина** после первого запуска используйте `npm run admin` в отдельном терминале, как описано ниже.

## Разработка и ручной запуск

Нужен Node.js 24 (версия среды — 24.19.0; SQLite встроен в Node.js).

```sh
cd /workspace/shohstore
npm ci
npm run dev
```

Vite слушает порт 5173, API — 3001. Vite направляет `/api` на сервер. Оба процесса запускает одна команда; Ctrl+C останавливает оба.

Готовая сборка:

```sh
npm run build
npm start
```

В этом режиме Express на порту 3000 обслуживает и API, и сайт. `PORT` меняет порт сервера. Для публичного размещения используйте HTTPS и `NODE_ENV=production`: cookie сессии получит флаг Secure. Домен, HTTPS, резервное копирование и постоянный диск настраиваются на хостинге отдельно.

`frontend.html` — исходный entrypoint приложения для Vite. `index.html` — автоматически собранная автономная версия для скачивания: не редактируйте её вручную. `npm run build` собирает серверный фронтенд в `dist/frontend.html` и обновляет автономный `index.html`. Только автономный HTML можно запускать без HTTP-сервера.

## Что работает

- Отдельная страница `/catalog`: 84 демонстрационных товара, по 6 в каждой из 14 категорий. Процессоры, видеокарты, платы AMD/Intel, память, SSD, блоки питания, водяное/воздушное охлаждение, корпуса, готовые ПК, мыши, клавиатуры и наушники. Главная показывает акционные предложения и подборки периферии.
- Поиск по названию, бренду и характеристикам; категории, сортировка по цене и избранное.
- Отдельные адреса `/product/<id>` с характеристиками; добавление товара открывает его страницу.
- Корзина-конструктор со схемой ПК, появляющимися компонентами, количеством, стоимостью и проверкой сокетов CPU/платы и типа RAM. Это не полная проверка питания, размеров и совместимости всех компонентов. Периферия сохраняется при замене компонентов на готовый ПК.
- Гостевая корзина сохраняется в браузере. После входа она объединяется с сохранённой корзиной пользователя в SQLite.
- Регистрация по имени **или** международному номеру и личному коду доступа от 6 символов. Номер проверяется на клиенте и сервере: требуется `+`, действующий код страны и корректный для страны формат номера (8–15 цифр); допускаются пробелы, скобки и дефисы. Проверку выполняет libphonenumber. Проверка принадлежности номера через SMS не подключена. Код задаёт сам пользователь; это пароль, не SMS-код.
- Коды хранятся как scrypt-хеши с индивидуальной солью. Сессии используют случайные токены и HttpOnly/SameSite cookie; вход ограничен по числу неудачных попыток. Админские операции проверяют роль на сервере.
- Оформление заказа и история заказов. Сервер самостоятельно рассчитывает сумму, проверяет остатки, сохраняет заказ, уменьшает остатки и очищает корзину в транзакции.
- Защищённая панель `/admin`: создание, редактирование и удаление товаров, описание на трёх языках, цена, цена до скидки, метка, остаток, категория, бренд, HTTPS-ссылка на изображение и произвольные характеристики. Без изображения используется лёгкая SVG-иллюстрация категории.

## Учётная запись администратора

Предустановленного пароля и публичной регистрации администраторов нет. В терминале сервера выполните:

```sh
npm run admin
```

Введите новое имя и личный код доступа; ввод кода скрыт. Затем войдите на сайте и выберите «Управление магазином» в личном кабинете. Скрипт не меняет существующие аккаунты и не повышает их роль.

Для автоматизированного первоначального создания можно безопасно передать `SHOHSTORE_ADMIN_NAME` и `SHOHSTORE_ADMIN_CODE` через окружение процесса. Не помещайте действующие коды в исходники, инструкции, общедоступные команды или историю shell.

## База данных

При первом запуске автоматически создаётся `data/store.sqlite` и демонстрационный каталог. Продукты, аккаунты, сессии, корзины и заказы сохраняются между запусками. Повторный запуск не восстанавливает удалённые товары и не затирает редактирование.

`SHOHSTORE_DB` позволяет указать другой путь к SQLite. Каталог `data/` исключён из Git; его необходимо сохранять на постоянном диске. Для резервной копии используйте SQLite backup API или остановите сервер и сохраните весь каталог `data`, включая WAL-файлы.

Обновление старой базы выполняется автоматически: добавляются новые демонстрационные модели и обновляются только неизменённые владельцем поля старых. Сохраняются пользовательские товары, изменённые цены/описания, остатки, удалённые модели, аккаунты и заказы. Для обновления скачанного проекта остановите магазин и замените файлы проекта, сохранив каталог `data/`. Перед обновлением сделайте резервную копию базы.

## Проверки

```sh
npm run build
npm test
```

Серверные тесты используют отдельную временную SQLite-базу и проверяют структуру каталога (6 моделей в каждой категории), безопасную миграцию старой базы, регистрацию, международные номера, вход, корзину, разграничение прав, CRUD товаров, совместимость, серверную стоимость, остатки, оформление заказа и выход. Они не меняют данные магазина.

Дополнительная браузерная проверка доступна в среде, где установлены Python Playwright и Chromium:

```sh
python3 tests/browser.py
python3 tests/standalone.py
python3 tests/launcher.py
```

`browser.py` запускает отдельный сервер с временной базой, проверяет весь путь от поиска до заказа, админский CRUD, три языка, обе темы и ширины 320/390/768/1440 px.

`standalone.py` проверяет один `index.html`, скопированный в пустую папку, без API и папок с ресурсами: каталог, навигацию, корзину, визуальную сборку, языки, темы, некорректный URL и повреждённое/запрещённое хранилище браузера. Дополнительно HTML запускается с непрозрачным origin без сети, чтобы проверить работу без импортов, CORS-зависимостей и внешних файлов.

`launcher.py` запускает полный магазин из отдельной копии проекта без зависимостей и сборки, затем проверяет повторный запуск и сохранность базы. Для первоначальной установки ему нужен доступ к npm (или прогретый npm-кеш).

Снимки браузерных проверок сохраняются в игнорируемом `test-results/`. Нестандартный путь к Chromium задаётся через `CHROMIUM_PATH`.

## Перед реальными продажами

Каталог и цены демонстрационные. Замените их действующими товарами через админ-панель и укажите реальные контакты, условия доставки и гарантии. Заявка сохраняется в базе; онлайн-оплата, SMS, уведомления магазину и интеграция с доставкой ещё не подключены. Платёжные данные сайт не запрашивает и деньги не списывает.

Новый растровый знак по мотивам исходного логотипа находится в `public/images/shohstore-logo.png`; интерфейс использует лёгкий векторный вариант. Компьютер на главной, в карточках корпусов и в конструкторе нарисован вектором с фиксированной геометрией. Схема компонентов меняется по составу корзины; диаграмма не является фотографией конкретного корпуса.
